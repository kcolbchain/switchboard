Each circle is an agent. Inner-core brightness = balance. Outer-ring color = wallet type. Hover reveals each agent's unique signature gradient — the visual stand-in for the PQ signature it would attach to a PaymentOffer / PaymentProof. Yellow rings = human-in-the-loop gate (click approve to release).
