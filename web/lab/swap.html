05 Protocol Pattern

Agentic Pay + Swap

Agent A hires Agent B for an inference job. B replies 402 Payment Required with an escrow-scheme offer. A’s x402 middleware checks it against a cap, an allowlist and a gas budget, then locks 5 USDC in AgentEscrow. B delivers; A confirms; the escrow releases. Then B does the agentic part — it routes its freshly-earned USDC through SafeSwap to rebalance into ETH for gas. One unattended loop, settled on-chain.

How it maps to code

From scene to scenario

Every step above corresponds to a real call in the Python demo.

x402 + escrow

Pay & settle

X402Middleware._validate_offer() enforces cap / allowlist / gas budget, then _pay_onchain() takes the escrow path: create_payment() locks funds, confirm_payment() releases them on delivery.

SafeSwap orchestrator

Route the proceeds

SafeSwapClient.quote() then .execute() hit the orchestrator API (/v1/quote, /v1/execute). Mockable in-process, so the whole flow runs with no node and no network. 

# PYTHONPATH=. python examples/agentic_demo/run.py --swap-to ETH
from examples.agentic_demo import run_scenario
result = run_scenario(swap_to="ETH")
assert result.settled           # escrow Released
assert result.swap_routed       # SafeSwap quote -> execute
